*** My Account Dashboard Builder Changelog ***

2026-10-15 - version 1.0.3
* Fix - Works cleanly alongside Advanced Coupons ( its menu no longer shows "undefined" ).
* Fix - Photos attached to returns are better protected.

2026-10-12 - version 1.0.2
* Tweak - Tested with WooCommerce 11.2.
* Fix - Works side by side with Advanced Coupons for WooCommerce.
* Fix - Shop managers can save the Settings.
* Fix - Photos attached to returns are private to the shop team and the customer.

2026-10-12 - version 1.0.1
* New - Design Studio: style the account area beside a live preview, starting from ready-made looks.
* New - A visual menu editor: drag, group, switch on or off, and choose who sees each item.
* New - View as a customer: see the account area exactly as a chosen customer does.
* New - Personal offers: banners that give each customer their own discount code.
* New - Returns, order cancelling, an address book and a privacy page for customers.
* New - Custom customer fields, such as a VAT number or birthday.
* New - Menus for customer groups, such as wholesale buyers.
* New - Rearrange the dashboard, status badges in the menu, and a built-in How to use guide.
* New - Insights: see which account pages and banners customers use.
* Tweak - The plugin's screen moved to WooCommerce → Account Dashboard.
* Fix - Many fixes to saving, the menu, banners, keyboard use and non-Latin names.

2026-09-01 - version 1.0.0
* First public release: a custom account menu, page content, banners, Buy again, recently viewed, order tracking, dashboard numbers and profile pictures.
