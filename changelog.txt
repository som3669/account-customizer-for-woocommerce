*** My Account Dashboard Builder Changelog ***

Unreleased
* New - Personal offers: a banner can give each customer who sees it a coupon of their own ( percent or amount off, for their email and one use, ending after N days, with an optional minimum spend and free shipping ). The banner shows the code with Copy and "Use it now", and {offer_code}, {offer_amount} and {offer_expiry} work in its text.
* New - Visibility rules for items and banners: "at most N orders" ( 0 = no orders yet ) and "last order more than N days ago". Banners get the product and order rules menu items have.
* New - Customer fields ( My Account → Fields ): text, long text, email, phone, number, date, dropdown, choices or tick box, on the registration form, the account details form and the admin order screen. Answers show on the user's profile, work as {field_key} smart tags and are part of personal data exports and erasure.
* New - Cancel orders: customers can cancel an order that has not shipped, within a set number of hours. A paid order gets a note to refund it.
* New - Returns: a Returns page and "Return items" on completed orders, within a set number of days. Customers choose items, a reason and can add a photo; the store is emailed. Answer each request on the Returns tab ( or the order screen's Returns box ) and the customer is emailed its status and your message.
* New - Address book: customers keep more addresses on the Addresses page, make one their shipping or billing address in a click, and pick one at the classic checkout.
* New - Privacy page: customers ask for a copy of their data or for it to be erased, through WordPress's own confirmed requests.
* New - Menus for customer groups: a menu of its own for customers with chosen roles, managed from a "Menu for" switcher on the Menu Items screen. Item settings are shared with the main menu.
* New - Insights ( My Account → Insights ): account page views per day and per page, banner views, clicks and click rate, and codes given, used and sales from each personal offer, over 7, 30 or 90 days. "Track endpoint views" became "Record usage".
* New - Appearance → Menus: a My Account box with a Log in / My account link and a My account link with the customer's account pages below it.
* New - Account pages from other plugins ( Subscriptions, Memberships, Bookings, points, wallets, tickets, affiliates ) get fitting icons, a Wishlist page is added for YITH and TI WooCommerce Wishlist, and {points_balance} reads YITH Points and Rewards and myCred.
* Tweak - A badge made only of smart tags that come back empty is hidden instead of showing a stray word ( "{points_balance} pts" without a points plugin ).
* Fix - An admin save that failed also said "Changes saved."
* New - Design Studio ( My Account → Design ): ready-made looks and your saved looks, controls grouped by what customers see, and the real account page beside them at desktop, tablet and phone widths. Live values change the preview as you pick them; the rest reload it from your unsaved draft, which only you see. Save or discard in one bar.
* New - Accent contrast check against WCAG AA, and one Density choice with a fine-tune option.
* Tweak - The Customizer panel and the Templates tab make way for the Studio; Appearance → Customize keeps a link to it.
* Fix - A warning in the admin sat on top of the floating Save button ( e.g. after an endpoint URL was refused ), so saving again meant closing it first. Notices now sit above the save bar.
* Fix - Saving the Settings tab showed no confirmation.
* Fix - Picking a Density preset in the Design Studio opened Fine-tune spacing.
* Tweak - The Visibility tab now says that an item's dates apply to shop managers too.
* Fix - Dashicons load for customers, who get no admin bar: the mobile menu button, pin stars, stat icons and avatar camera were blank.
* New - Menu items: an editable endpoint URL for custom endpoints, checked against WooCommerce's endpoints, WordPress query vars and the rest of the menu.
* New - Menu items: a badge ( e.g. "New", or "{points_balance} pts" ) shown in place of the item count.
* New - Visibility rules: "bought any of" with a product search, a minimum number of orders and a minimum total spent. Dates now follow the site timezone.
* New - Groups: a "Start expanded" switch per group; a group holding the current page opens on its own.
* New - Design Studio: an info icon beside every control; hover it ( or focus the control ) for what it changes.
* Tweak - Banners: settings in General / Style / Link / Visibility tabs, like a menu item's, with a count of visibility rules.
* New - Banners: choose what the count badge shows ( orders, downloads, items in cart, reward points ), set the link text, and schedule a banner with show-from / show-until dates.
* New - Dashboard: stat cards link to the page they summarise, and the profile meter lists what is missing with a link to each form.
* New - Smart tags: {total_spent}, {member_since}, {cart_count}, {billing_phone}, {billing_city}, {billing_country}, {account_url}, {shop_url}, {site_url}.
* New - Custom endpoints get their menu label as the page title.
* New - Menu Items screen: the menu is drawn the way customers see it, in the look saved in the Design Studio. Drag an item to reorder it or into a group ( Alt + arrow keys from the keyboard ); "Add to menu" adds an endpoint, group, link or page; every item has its on/off switch, with Duplicate and Delete on hover; each item says who can see it ( e.g. "Customer · 2+ orders" ); switched-off items stay visible, dimmed. The item's settings open beside it in General / Content / Visibility / Advanced tabs, with its on/off switch, Duplicate and Delete. A save bar says when there are unsaved changes, and leaving with unsaved edits asks first.
* Tweak - The header's Add endpoint / Add group / Add link / Add page buttons make way for "Add to menu" under the menu.
* Tweak - AJAX navigation handles Back / Forward, opens new tabs on Ctrl / Cmd-click, moves the active state and keeps focus for screen readers.
* Tweak - Menu search keeps a group when one of its items matches; pinning favourites works without a reload and per customer.
* Tweak - Order counts for the dashboard are cached per customer and cleared when their orders change.
* Tweak - The icon library is sent once per admin page instead of once per icon picker ( the Menu Items screen is a third lighter ).
* Tweak - Applying a template keeps your Custom CSS, avatar settings and item-count setting.
* Fix - Custom endpoints showed the WooCommerce dashboard ( greeting and dashboard widgets ) under their own content.
* Fix - An endpoint's banner position was never saved.
* Fix - Items with a label in a non-Latin script ( Devanagari, Cyrillic, CJK… ) disappeared from the menu after the first save.
* Fix - Adding an item named like an existing one ( e.g. "Orders" ) overwrote it; a new banner with an existing banner's name replaced it.
* Fix - Endpoints inside a group got no rewrite rule.
* Fix - The Customizer's accent colour, text colour and corner radius did not reach the menu or the dashboard widgets.
* Fix - Banner colours with transparency ( rgba ) were reset to the defaults.
* Fix - Smart tags in a banner title were escaped twice, so a name like D'Angelo showed as "D&#039;Angelo".
* Fix - The "Reward points" stat was always empty.
* Fix - Switching Buy again or Recently viewed off left a dead tab in a saved menu; switching one on for the first time did not register its URL.
* Fix - The "Default endpoint" setting did nothing. My Account now opens on it, and the dashboard moves to /dashboard/.
* Fix - Log out went through WooCommerce's "Are you sure?" page.
* Fix - Keyboard users had no focus outline in the menu and could not open groups; the pin star stayed invisible on focus.
* Fix - The "Add smart tags" button disappeared from an editor once it was opened.
* Fix - Presets, imports and saves returned to the wrong place, and warnings vanished before they could be read.
* Fix - Reset flushed the whole object cache; it now deletes the plugin's options one by one.

2026-09-01 - version 1.0.0
* First public release.
* New - Menu builder: endpoints, pages, links and collapsible groups, drag-to-reorder, per-item icons (Font Awesome, Dashicons or uploaded).
* New - Per-endpoint content with the Classic or the Gutenberg block editor, placed before, after or instead of the default WooCommerce output.
* New - Visibility rules by user role, date range and purchased product.
* New - Starter design templates applied in one click.
* New - Customizer panel (Avatar / Navigation / Layout & Colors) with live preview, reusable presets and a Custom CSS field.
* New - Customer avatar upload with extension, MIME and image validation, overriding the Gravatar site-wide.
* New - Buy again tab and dashboard tile for one-click reordering of previously purchased products.
* New - Recently viewed tab.
* New - Order tracking summary on the dashboard, auto-detecting WooCommerce Shipment Tracking and falling back to a status timeline.
* New - Dashboard stats, orders-by-status chart, quick-link tiles and a profile completeness meter.
* New - Dashboard notice: an admin-authored message shown at the top of the account dashboard, with style options and optional dismissal.
* New - Per-endpoint promotional banners with role targeting.
* New - Smart tags for personalised labels and content ({display_name}, {first_name}, {order_count}, {last_login} and more).
* New - Shortcode, block and widget for rendering the account menu anywhere.
* New - Optional AJAX endpoint navigation, login and logout redirects, and a configurable landing endpoint.
* New - JSON import / export of the whole configuration, plus a full reset tool.
* New - WPML and Polylang string registration; HPOS and cart/checkout blocks compatibility declared.
