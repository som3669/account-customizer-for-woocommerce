# Marketplace media pack

From [Woo product page content and assets](https://developer.woocommerce.com/docs/woo-marketplace/product-page-content-and-assets/):

- **Product icon:** 160×160 PNG → Product Data → Woo Product Data → Product Icon
- **Product image (featured):** set first via “Set product image” (min 555×416; gallery images 896×550+)
- **Product gallery:** Add product gallery images — upload the rest in order

## Upload order

| File | Use as | Notes |
| --- | --- | --- |
| `product-icon-160.png` | Product icon | Not the featured image |
| `01-product-image-frontend-dashboard.png` | **Set product image** | Front-end dashboard (best hero) |
| `02` … `07` | Gallery (after featured) | Admin + features |
